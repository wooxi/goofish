# 闲管家虚拟商品进销存系统

面向闲鱼虚拟商品与卡密商家的全周期进销存管理工作台，涵盖商品运营、卡密货源采购、订单发卡履约、售后退款与利润核算。

## 核心功能

### 1. 经营总览（仪表盘）
- 汇总展示累计实付营收、发卡成本、净毛利润、卡密可用库存与待处理履约数
- 近 7 日营收、成本与净毛利趋势图表
- 低库存卡种预警与店铺授权到期（30 天内）提醒

### 2. 商品全周期管理
- 按状态分栏检索：全部、待发布/草稿、销售中、已下架/售罄、异常商品
- 一键全量同步在架及历史未上架商品
- 创建商品与完整详情编辑：店铺选择、类目与属性拉取、标题描述、多规格 SKU、定价库存、成色与服务项、定时上架、发货省市区联动
- 支持商品主图与白底图直接上传并管理排序
- 支持商品上架、下架、库存调整、异常商品清理及绑定本地卡种/固定成本

### 3. 货源与卡密库存
- 卡密分类管理（创建、编辑、删除、同步）
- 卡种管理（创建、编辑、库存预警阈值与成本设置）
- 发卡组合管理（组合列表、启停控制、删除）
- 本地卡密明细池：按卡号检索、作废标记与 TXT 导出
- 供应商名录与采购批次台账：支持文本粘贴或 `.txt`/`.csv` 文件批量采购入库，并同步推送至闲管家卡密库

### 4. 订单与发货履约
- 按订单状态（待付款、待发货、已发货、交易成功、已关闭）及授权店铺筛选
- 全量订单同步与单笔毛利自动核算
- 无需物流发卡密与待付款订单改价
- 订单详情与发出卡密明细查看（卡号、卡密、售出方式、单卡成本）

### 5. 售后退款
- 按售后状态分栏筛选（待处理、待退货、待收货、退款成功、已拒绝、已关闭）
- 售后详情查看（申请金额、已退金额、退款原因、超时时间）
- 同意退款与拒绝退款（支持原因说明及举证图片上传）

### 6. 经营报表与系统管理
- 多维度经营报表：按商品利润与供应商采购汇总统计，支持导出订单对账 CSV
- 授权店铺管理：店铺状态、鱼小铺标识、订购状态与授权到期倒计时
- 同步日志与系统设置：应用凭证配置、连通性测试、图床配置与回调地址管理

## 技术栈

- **前端**：Next.js (App Router)、TypeScript、Tailwind CSS、shadcn/ui、TanStack Table、Recharts
- **后端与存储**：Next.js Route Handlers、Prisma ORM、SQLite

## 快速部署

### Docker Compose（推荐）

```bash
docker compose up -d --build
```

默认访问地址：`http://<服务器IP>:3000`

### 本地开发

```bash
cp .env.example .env
npm install
npx prisma db push
npm run dev
```

访问 `http://localhost:3000`。
